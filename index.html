Two lenses, one careful answer

Machine learning.
Human-readable evidence.

Local Naive Bayes weighs words learned from a public SMS dataset. A separate rule layer checks code requests, payment pressure and impersonation. Link analysis only reads the URL text.

What it cannot do

It cannot verify a sender, detect AI-generated text, judge a link's reputation, read attachments or prove a message is safe. Non-English and short messages need manual checks. High spam likelihood is not the likelihood of fraud.

If money or personal data is at stake, use an official app or a known contact, not the message's link or number.

Model evaluation and limits

Threshold 0.90, set before evaluation. No modern scam benchmark has been run. Zero false positives in this sample is not a guarantee. Model likelihoods are not calibrated.
